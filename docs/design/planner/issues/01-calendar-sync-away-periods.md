# Calendar sync for away periods

Status: needs-triage
Type: later / not in v1

Read the user's calendar (Google, Outlook, or KDE calendar) and mark days with relevant events as **away periods**, instead of entering them by hand in the tray popup.

## Context

- v1 uses manual entry in the popup (decided in grilling session).
- Open problem: telling which events mean "car is away" (e.g. an all-day event at the office vs. a reminder). Needs a rule, such as a keyword, a dedicated calendar, or a location field.
