# Android set-up: decisions

Decisions about the Android app's first-run set-up and its plain Today screen that the code alone does not explain. Newest last; each names the date and the issue or pull request that settled it. The 18 decisions of the assumption check are on #314 (comment of 2026-11-02); this list keeps the ones a later change is most likely to meet.

- **2026-11-02, #314: set-up is seven steps, without a navigation library.** Welcome, Location, Panels, Car, Charger, More (the house and weekly away on one page) and Check. Back on Welcome closes the app at once; on a later step it goes one step back and keeps what was entered. Back while the check runs cancels it; Back while Finish saves does nothing until the save ends, and the outcome then decides the screen.
- **2026-11-02, #314: Finish.** While saving, Finish is off and shows progress. Saved opens the Today screen without a message (the screen calls `shown(Saved)` itself). Failed keeps the English details and **Try again** on the Check step, in a live region. A settings file of a newer version opens the "update the app" screen. A value the engine refuses goes back to the first step with a refused value, with a line that says why.
- **2026-11-02, #314: the check runs on entering the Check step**, again on coming back to it, and again after the system ended the app. A failure shows **Check again** and the English details; Finish stays on.
- **2026-11-02, #314: the time zone.** It is chosen under **Advanced** from the list of zone ids only. A chosen place sets it; typed coordinates put it back to the phone's zone unless the owner chose one by hand. The phone's zone is read when it is used, not when the app starts. A zone loaded from a saved file counts as not chosen by hand, so in Settings (#315) typing coordinates also resets it, unless #315 decides otherwise.
- **2026-11-02, #314: the place search** runs on the Search button or the keyboard's Search key, never per keystroke, and sends the app's resolved language (`place_search_language`, `en` or `nl`). It shows at most 8 places; labels read alike only among those shown. The typed text is kept at most 100 characters and survives the system ending the app; the results do not.
- **2026-11-02, #314: a language change reaches the forms and the search without losing what was typed.** The view model is kept and told the new language in each `onCreate`; numbers typed before the change keep their decimal mark, which is read either way.
- **2026-11-02, #314: words.** The heading for an unusable settings file is "Settings file cannot be used"; the Dutch stays "Niet ingesteld", as `docs/translating.md` gives for Unusable config (#325 brings the desktop in line). In Dutch a weekly away period is "afwezigheid" throughout, its controls named with its number ("Afwezig tot, afwezigheid 2").
- **2026-11-02, #314: tests.** Screen tests run on Robolectric only. Compose's own accessibility checks are not used, as they find nothing there; the explicit checks (name, role, a drawn size of 48 dp, scrolling at font scale 2) replace them. What TalkBack really says is the maintainer's walk before a release.
